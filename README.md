# java-package

A project template with only the bare minimum of structure. A good starting point for a small project.

## Start

```bash
make run-dist
```

## Setup

```bash
make build
```

## Run

```bash
make run
```

## Run tests

```bash
make test
```

## Run checkstyle

```bash
make lint
```

## Check update dependencies and plugins

```bash
make update
```
## Play Calculator Game 
```bash
make play-calc
```

## Play Even Game
```bash
make play-even
```

## Play GSD Game
```bash
make play-gsd
```

## Play Prime Game
```bash
make play-prime
```

## Play Progression Game
```bash
make play-progression
```
